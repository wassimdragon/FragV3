Scientific Problem

The Combinatorial Cleavage Challenge

Identifying unknown compounds in Mass Spectrometry involves cleaving chemical bonds and checking generated fragments against measured m/z values.

  • ✓ Exponential Complexity: Cleaving $N$ bonds creates $O(2^N)$ sub-compounds.
  • ✓ Scientific Constraints: Fragments must respect valency rules and chemical feasibility.
  • ✓ The Workflow bottleneck: Running combinatorics in Python and visualizing results in 3D is time consuming.

AI Co-Pilot Achievement

Overcoming the 100MB GitHub File Limit

The Limit: GitHub 100MB File Restriction

For complex molecules, fragment data JSON caches easily exceed 100MB, which blocked hostability on GitHub Pages.

The AI Solution: Autonomous Chunking Engine

Google Antigravity designed a multi-part file pipeline completely on its own, resolving the platform limitations.

How the AI Built the Bridge:

  • ⚡ Python Splitter: Auto-detects target directory and segments huge JSON files into sub-100MB chunks before commits.
  • ⚡ JS Reconstructer: Rewrote browser fetching logic to stream individual chunks concurrently and re-compile arrays on-the-fly.
  • ⚡ Zero Overhead: Scientists run code as usual; AI handles limits seamlessly.
